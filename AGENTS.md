# Repository AI guidelines

Before creating or modifying code, read and follow the shared
[code-formatting skill](.github/skills/code-formatting/SKILL.md).
Apply it to every code-editing task, not just explicit formatting requests.
Treat the root [.editorconfig](.editorconfig) as the formatter configuration.

Apply these rules to new and changed code; do not reformat unrelated code or
generated files. Preserve existing user edits and program behavior.
For other languages and file formats, follow their existing conventions and
syntax rather than applying C# syntax rules.

Before finishing, format the changed C# files and review all changed code
against the skill's checklist. Report any unavailable validation or remaining
violations explicitly; do not claim formatter checks enforce every guideline.
